# Dataflow: a framework for mapping statistical production

Dataflow is a way of drawing a statistical production process so that every system and data set in it fits on one sheet. It shows how data move from collection to dissemination, which systems handle them on the way, and where they change state: from micro data to macro data, statistics and published figures.

The framework adds two things to the drawing. It splits the picture into levels and lenses, so each drawing answers one question for one audience. And it describes the target state as needs rather than solutions, so a platform migration can be used to improve the process, not only to move it.

!!! info "Where it comes from"
    Dataflow was developed at Statistics Norway from 2021, in three rounds. About 120 production processes have been drawn with version 2.0. This English edition presents version 3.0 as a framework that other statistical organisations can adopt and adapt. Statistics Norway’s own use is the worked example in [chapter 6](6-example-statistics-norway.md). The [Norwegian edition](https://thomasbjornskau.github.io/ssb-dataflyt/) describes the same method as it is used internally.

!!! warning "Draft"
    Version 3.0 is being tested. The templates and the AI skill are drafts, and the worked example contains interpretations that have not been confirmed by the subject-matter owners.

## Where to start

- **Considering the framework for your organisation?** Read chapter 1, look at the example in chapter 6, and then read chapter 8.
- **Mapping a statistic?** Read chapter 5 and go to the [templates](template/index.md). Keep chapter 2 at hand.
- **Reading or reviewing a drawing?** Read chapters 2 and 3.
- **Drawing yourself,** with Excel and Tableau or with AI support? Read chapters 4 and 7.

## The templates

Three [templates](template/index.md) collect what a mapping needs: process steps and roles (D1), data and systems (D2), and needs and value (D3). They can be filled in on this site. With one click, they produce a text you can give to an AI assistant, which turns it into a model, drawings and a list of what must be checked.

## The graphics

Every symbol is available as SVG under [graphic elements](graphic-elements.md). The concept figures are SVG in 16:9 and can be placed straight into a slide. See the [list of figures](figures.md).
